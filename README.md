# Проект зала

Редактор ремонта жилой комнаты: 3D-визуализация, план мебели, электрика и чертежи А3 для мастеров.

Открыть: https://dmitro2103.github.io/proekt-zala/

## Что умеет

- **Мебель**: переставить, повернуть, растянуть или укоротить (на плане — за квадратики по краям, поворот — за кружок; в 3D — перетаскиванием), добавить из каталога, скопировать, удалить.
- **Отделка**: жидкие обои, покраска, однотонные обои или обои с узором (дамаск, полоска, геометрия, листья, горошек), любой цвет, акцентная стена; пол (линолеум, дуб, орех, ёлочка, плитка), плинтус, шторы (лён, блэкаут, римские, тюль).
- **Свет и электрика**: люстры (7 видов, металл, плафоны), бра, точечные и подвесные светильники, розетки и блоки до 4 модулей (220 В, USB, LAN, ТВ), выключатели до 3 клавиш с привязкой к светильникам, резерв под кондиционер.
- **Комната**: размеры, проём, балконный блок — мебель у дальних стен едет вместе со стенами.
- **Чертежи А3** (обновляются сами): план расстановки мебели с экспликацией и ведомостью отделки, план электрики с обозначениями и ведомостью точек, развёртки четырёх стен с высотами. Печать в PDF и скачивание SVG.
- Отмена/повтор (Ctrl+Z / Ctrl+Shift+Z), автосохранение в браузере, ссылка «Поделиться» (весь проект в ссылке), сохранение и открытие файла проекта.

Клавиши при выделенном предмете: стрелки — сдвиг на 1 см (Shift — 10 см), PageUp/PageDown — высота, R — поворот на 90°, Ctrl+D — копия, Delete — удалить, Esc — снять выделение.

## Сборка

Страница — один автономный файл `index.html`: three.js r147 и шрифты встроены, внешних запросов нет.

```
npm install
python3 build.py          # --dev — без минификации кода приложения
```

Исходники: `src/style.css`, `src/body.html`, `src/js/1-core.js … 8-main.js` (модель и каталог, текстуры, 3D-модели, сцена, план-редактор, панели, чертежи, запуск).
